# ⚙️ E-Commerce Store Backend

Backend server for the MERN E-Commerce Store, built with **Node.js**, **Express.js**, and the **Stripe API**.

## 🚀 Live Endpoint
- **Base URL:** [https://stripe-backend-3qm2.onrender.com]

---

## 🛠️ Tech Stack
- Node.js & Express.js
- Stripe SDK (`stripe`)
- CORS & Dotenv

---

## ⚙️ Environment Variables (`.env`)
Create a `.env` file in the root directory and add the following keys:
```env
PORT=5000
STRIPE_SECRET_KEY=your_stripe_secret_key_here
CLIENT_URL=your_netlify_frontend_url_here


# Install dependencies
npm install

# Start development server
npm run dev
